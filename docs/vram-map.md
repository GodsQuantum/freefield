# VRAM map

Generated by `python tools/catalog.py vram` from the apps' `app.json`. Weight sizes come from the Hugging Face Hub;
activations are **not** included. Local target: one 24 GB card (RTX 3090 Ti) keeping 4 GB of headroom.

When two apps run back to back with different models, the gateway asks ComfyUI to unload everything first
(`POST /free`), so the previous app never stays in VRAM.

*Measured* records historical lab peaks on the GPU shown. Workflows without a matching measurement show
`not measured`. The original results remain in [the lab example index](../web/examples/index.json).
On an 80 GB H100, ComfyUI can keep models from earlier phases loaded, so measured peaks vary by device and offloading policy.
